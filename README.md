# Warraq | ورّاق — Document Assistant

مساعد مستندات بالعربية والإنجليزية جاهز للنشر من GitHub إلى Vercel، مع Gemini وبحث هجين يجمع المعنى والكلمات. المستخدم لا يحتاج لتنزيل برنامج أو نموذج AI.

## النشر على Vercel

1. ارفع محتويات المجلد إلى جذر الريبو، خصوصًا api/ وlib/ وpublic/ وpackage.json وvercel.json. ارفع الكود، وليس ZIP.
2. اختر Add New → Project في Vercel واستورد الريبو.
3. Framework Preset: Other. لا يلزم Build Command. Output Directory: public؛ vercel.json يضبطه تلقائيًا.
4. أضف مرة واحدة في Settings → Environment Variables:

| Name | Value |
| --- | --- |
| GEMINI_API_KEY | مفتاح Google AI Studio |
| GEMINI_MODEL | gemini-3.5-flash-lite |
| GEMINI_EMBEDDING_MODEL (اختياري) | gemini-embedding-2 |

5. انشر المشروع. بعد تعديل متغيرات البيئة اعمل Redeploy.

المفتاح يبقى على السيرفر. المستخدمون لا يحتاجون لإدخال مفتاح بعد ضبطه على Vercel، وحصة API مشتركة بينهم.

## الخطة المجانية

اعمل المفتاح في https://aistudio.google.com/apikey باستخدام مشروع Free Tier بدون تفعيل Paid Billing. Gemini 3.5 Flash-Lite له خطة مجانية بحدود استخدام. وجود المفتاح لا يضمن أن حسابك على Free Tier؛ تحقق من AI Studio. التطبيق لا يستخدم OpenAI، ولا ينقل الطلبات تلقائيًا إلى خدمة مدفوعة. عند انتهاء الحصة يعرض خطأ. للاستضافة حدود وخطط منفصلة؛ راجع أهلية مشروعك لخطة Vercel التي تختارها.

إذا لم تضبط مفتاحًا على السيرفر، يعمل البحث بالمقتطفات الأصلية بلا توليد AI. يظهر أيضًا زر مفتاح شخصي للجلسة؛ يُرسل للخادم للاستخدام مع Google، ولا يُحفظ في ملفات أو LocalStorage.

## الميزات

- واجهة دارك عربية RTL وإنجليزية LTR، مع زر تبديل اللغة وتذكّر اختيارها.
- إضافة لشاشة الهاتف باسم Warraq وأيقونة PNG مخصصة للآيفون، مع فتح مستقل؛ الإنترنت مطلوب للذكاء الاصطناعي.
- أسئلة وأجوبة بالعربي والإنجليزي، حتى عند اختلاف لغة المستند عن السؤال.
- دعم PDF وWord (.docx) وTXT وPowerPoint (.pptx)، حتى 20 MB.
- مصادر حسب النوع: صفحات PDF، أقسام Word، أجزاء TXT، أو شرائح PowerPoint؛ أرقام Word وTXT ليست صفحات مطبوعة.
- قراءة صفوف وأعمدة الجداول النصية، دون OCR للصور.
- Word وPowerPoint القديمان (.doc و.ppt) يلزم حفظهما بصيغة .docx و.pptx.
- بحث هجين: BM25 مع تطبيع عربي ومرادفات بسيطة، وGemini Embedding 2 للبحث بالمعنى، ودمج ترتيب النتائج.
- إعادة صياغة عند الحاجة للأسئلة العامية وأسئلة المتابعة؛ السؤال المباشر يتجنب هذا الطلب.
- ترتيب إضافي للأدلة وضغط المقاطع المتداخلة، ومراجعة مستقلة للحسابات والمقارنات.
- جولة بحث ثانية واحدة عند نقص أدلة مستند كبير، ضمن مهلة إجمالية 48 ثانية.
- سياق آخر أربع محادثات لفهم أسئلة المتابعة؛ الحقائق تُستمد من المصادر فقط.
- المستندات الصغيرة تُرسل بكامل المقاطع بعد إزالة التداخل؛ للمستندات الكبيرة تُضاف المقاطع المجاورة لحفظ التواريخ والجداول والشروط.
- استنتاجات وحسابات من المعلومات الموجودة، مع توضيح الطريقة وتجنّب احتساب المدد المتداخلة مرتين.
- إجابات Gemini منظمة مع مصادر وأرقام صفحات، والتحقق من معرفاتها.
- فتح الصفحة الأصلية وتصدير المحادثة.
- دوال Vercel في api/chat.js وapi/config.js بدون تبعيات إضافية.

## الخصوصية والمفاتيح

الملف الأصلي لا يُرفع. النص المستخرج يُرسل لخادم التطبيق. عند تفعيل AI تُرسل مقاطع المستند إلى Google لبناء embeddings، ثم السؤال والمقاطع المختارة وآخر أربع محادثات لتوليد الإجابة. التطبيق لا يكتب المستندات أو المحادثات أو مفاتيح الجلسة إلى قاعدة بيانات أو قرص. تُخزّن الإجابات الناجحة مؤقتًا في ذاكرة السيرفر لعشر دقائق (100 نتيجة، حد 4 MB)، بمفتاح معزول ببصمة المستند والسؤال والمفتاح وإعدادات النموذج والسياق والتاريخ. قد تحتوي الإجابة على معلومات من المستند؛ لا يُحفظ نص المستند في كاش الإجابات، وتُعاد المقاطع من الطلب الحالي. يحتفظ بمتجهات embeddings وبصمات مشفّرة في ذاكرة عملية السيرفر لعشر دقائق، بحد 2400 متجه؛ لا يخزّن نص المستند أو المفتاح في هذا الكاش. الكاش غير مضمون عبر cold starts في Vercel. لغة الواجهة وحدها تُحفظ في LocalStorage. قد تستخدم Google محتوى الخطة المجانية لتحسين منتجاتها؛ راجع سياستها قبل استخدام مستندات حساسة.

لا ترفع .env إلى GitHub؛ .gitignore يستثنيه. لا تضع المفاتيح في public/ أو vercel.json أو متغيرات VITE_/NEXT_PUBLIC_. انسخ المفتاح مباشرة إلى Vercel Environment Variables، لا إلى المحادثة.

## الاختبارات

شغّل npm test أو node --test tests/*.test.mjs. تشمل النسخة 50 اختبارًا للاسترجاع والمصادر والـAPI وGemini ودوال Vercel. نجح أيضًا اختبار حي للبحث الهجين: سؤال عربي عن التقسيط في مستند إنجليزي، إجابة عربية من الصفحة الصحيحة، وسؤال متابعة بإجابة إنجليزية. سؤال خارج المستند أعاد notFound دون مصادر. نُشرت الواجهة على Vercel وتم التحقق من الثيم الدارك وتحميل اللوجو. بعد تغيير إعدادات Gemini، جرّب سؤالًا على ملفك للتحقق من إعدادات الإنتاج.

## تطوير محلي اختياري

للمطور فقط: Node.js 22، ثم npm start أو start.cmd. انسخ .env.example إلى .env واضبط Gemini إذا أردت. مستخدم الموقع المنشور لا يحتاج لأي تشغيل محلي. لا تحتاج npm install لأن PDF.js مرفقة.

## الحدود

OCR غير مضاف. البحث بالمعنى يستخدم Gemini Embedding 2؛ عند عدم إتاحته أو تجاوز مهلة الفهرسة (12 ثانية) يعود إلى الكلمات ويُظهر الوضع الفعلي بجانب الإجابة. توليد الإجابة يبقى خاضعًا لحصة Gemini. سياق المحادثة محدود لآخر أربع رسائل، ويُمسح عند تغيير المستند أو بدء محادثة جديدة. في المستندات الكبيرة، التلخيص يستخدم مقاطع موزعة مع سياق مجاور ولا يضمن كل التفاصيل. الحسابات والتقديرات تُنتج بالنموذج ويجب مراجعتها مقابل المصادر. صحة معرف المصدر لا تضمن صحة كل استنتاج، فراجع الصفحة الأصلية.

## استهلاك الطلبات

في اختبار حي: السؤال المباشر استخدم طلب توليد واحد، وتكراره المطابق استخدم صفر طلبات توليد وembeddings. سؤال حساب جدول استخدم طلبين للتوليد والمراجعة. الأسئلة العامية/المتابعة قد تحتاج طلب إعادة صياغة، والبحث الثاني قد يضيف طلبات. هذه وفورات للحالات المذكورة وليست ضمانًا لعدد ثابت أو جودة مطلقة. الكاش مؤقت وغير مضمون عبر Vercel cold starts.

### iPhone / Safari compatibility

PDF.js uses the official legacy build (5.6.205). Office ZIP extraction uses a bounded output buffer with fflate 0.8.2 (MIT; license included), so it does not require native deflate-raw DecompressionStream support. Page and installed-app titles stay Warraq in both languages. Re-add an existing iPhone home-screen shortcut to update its saved name.
