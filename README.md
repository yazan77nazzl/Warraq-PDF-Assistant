# Warraq | ورّاق — Bilingual PDF Assistant

تطبيق PDF بالعربية والإنجليزية جاهز للنشر من GitHub إلى Vercel، مع Gemini وبحث هجين يجمع المعنى والكلمات. المستخدم لا يحتاج لتنزيل برنامج أو نموذج AI.

## النشر على Vercel

1. ارفع محتويات المجلد إلى جذر الريبو، خصوصًا api/ وlib/ وpublic/ وpackage.json وvercel.json. ارفع الكود، وليس ZIP.
2. اختر Add New → Project في Vercel واستورد الريبو.
3. Framework Preset: Other. لا يلزم Build Command. Output Directory: public؛ vercel.json يضبطه تلقائيًا.
4. أضف مرة واحدة في Settings → Environment Variables:

| Name | Value |
| --- | --- |
| GEMINI_API_KEY | مفتاح Google AI Studio |
| GEMINI_MODEL | gemini-3.5-flash-lite |
| GEMINI_EMBEDDING_MODEL (اختياري) | gemini-embedding-2 |

5. انشر المشروع. بعد تعديل متغيرات البيئة اعمل Redeploy.

المفتاح يبقى على السيرفر. المستخدمون لا يحتاجون لإدخال مفتاح بعد ضبطه على Vercel، وحصة API مشتركة بينهم.

## الخطة المجانية

اعمل المفتاح في https://aistudio.google.com/apikey باستخدام مشروع Free Tier بدون تفعيل Paid Billing. Gemini 3.5 Flash-Lite له خطة مجانية بحدود استخدام. وجود المفتاح لا يضمن أن حسابك على Free Tier؛ تحقق من AI Studio. التطبيق لا يستخدم OpenAI، ولا ينقل الطلبات تلقائيًا إلى خدمة مدفوعة. عند انتهاء الحصة يعرض خطأ. للاستضافة حدود وخطط منفصلة؛ راجع أهلية مشروعك لخطة Vercel التي تختارها.

إذا لم تضبط مفتاحًا على السيرفر، يعمل البحث بالمقتطفات الأصلية بلا توليد AI. يظهر أيضًا زر مفتاح شخصي للجلسة؛ يُرسل للخادم للاستخدام مع Google، ولا يُحفظ في ملفات أو LocalStorage.

## الميزات

- واجهة دارك عربية RTL وإنجليزية LTR، مع زر تبديل اللغة وتذكّر اختيارها.
- أسئلة وأجوبة بالعربي والإنجليزي، حتى عند اختلاف لغة المستند عن السؤال.
- PDF نصّي حتى 20 MB و200 صفحة؛ PDF.js مرفقة.
- بحث هجين: BM25 مع تطبيع عربي ومرادفات بسيطة، وGemini Embedding 2 للبحث بالمعنى، ودمج ترتيب النتائج.
- إعادة صياغة ذكية للأسئلة العامية وأسئلة المتابعة، مع عبارات بحث عربية وإنجليزية.
- سياق آخر أربع محادثات لفهم أسئلة المتابعة؛ الحقائق تُستمد من المصادر فقط.
- المستندات الصغيرة تُرسل بكامل المقاطع؛ للمستندات الكبيرة تُضاف المقاطع المجاورة لحفظ التواريخ والجداول والشروط.
- استنتاجات وحسابات من المعلومات الموجودة، مع توضيح الطريقة وتجنّب احتساب المدد المتداخلة مرتين.
- إجابات Gemini منظمة مع مصادر وأرقام صفحات، والتحقق من معرفاتها.
- فتح الصفحة الأصلية وتصدير المحادثة.
- دوال Vercel في api/chat.js وapi/config.js بدون تبعيات إضافية.

## الخصوصية والمفاتيح

ملف PDF الأصلي لا يُرفع. النص المستخرج يُرسل لخادم التطبيق. عند تفعيل AI تُرسل مقاطع المستند إلى Google لبناء embeddings، ثم السؤال والمقاطع المختارة وآخر أربع محادثات لتوليد الإجابة. التطبيق لا يكتب المستندات أو المحادثات أو مفاتيح الجلسة إلى قاعدة بيانات أو قرص. يحتفظ بمتجهات embeddings وبصمات مشفّرة في ذاكرة عملية السيرفر لعشر دقائق، بحد 2400 متجه؛ لا يخزّن نص المستند أو المفتاح في هذا الكاش. الكاش غير مضمون عبر cold starts في Vercel. لغة الواجهة وحدها تُحفظ في LocalStorage. قد تستخدم Google محتوى الخطة المجانية لتحسين منتجاتها؛ راجع سياستها قبل استخدام مستندات حساسة.

لا ترفع .env إلى GitHub؛ .gitignore يستثنيه. لا تضع المفاتيح في public/ أو vercel.json أو متغيرات VITE_/NEXT_PUBLIC_. انسخ المفتاح مباشرة إلى Vercel Environment Variables، لا إلى المحادثة.

## الاختبارات

شغّل npm test أو node --test tests/*.test.mjs. تشمل النسخة 38 اختبارًا للاسترجاع والمصادر والـAPI وGemini ودوال Vercel. نجح أيضًا اختبار حي للبحث الهجين: سؤال عربي عن التقسيط في مستند إنجليزي، إجابة عربية من الصفحة الصحيحة، وسؤال متابعة بإجابة إنجليزية. سؤال خارج المستند أعاد notFound دون مصادر. نُشرت الواجهة على Vercel وتم التحقق من الثيم الدارك وتحميل اللوجو. بعد تغيير إعدادات Gemini، جرّب سؤالًا على ملفك للتحقق من إعدادات الإنتاج.

## تطوير محلي اختياري

للمطور فقط: Node.js 22، ثم npm start أو start.cmd. انسخ .env.example إلى .env واضبط Gemini إذا أردت. مستخدم الموقع المنشور لا يحتاج لأي تشغيل محلي. لا تحتاج npm install لأن PDF.js مرفقة.

## الحدود

OCR غير مضاف. البحث بالمعنى يستخدم Gemini Embedding 2؛ عند عدم إتاحته أو تجاوز مهلة الفهرسة (12 ثانية) يعود إلى الكلمات ويُظهر الوضع الفعلي بجانب الإجابة. توليد الإجابة يبقى خاضعًا لحصة Gemini. سياق المحادثة محدود لآخر أربع رسائل، ويُمسح عند تغيير المستند أو بدء محادثة جديدة. في المستندات الكبيرة، التلخيص يستخدم مقاطع موزعة مع سياق مجاور ولا يضمن كل التفاصيل. الحسابات والتقديرات تُنتج بالنموذج ويجب مراجعتها مقابل المصادر. صحة معرف المصدر لا تضمن صحة كل استنتاج، فراجع الصفحة الأصلية.
